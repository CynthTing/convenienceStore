# 統家補貨中控台

這是一個給便利商店店長使用的自動補貨系統介面原型，直接開啟 `index.html` 即可展示。

## 系統設計

- **需求預測模型：加權移動平均**：使用近 28 日銷售資料，近期資料權重較高，並加入星期、時段與促銷係數，預測未來 7 日需求。
- **庫存管理模式：定期檢查制（R,S）**：每日固定時間檢查庫存，將庫存補至目標水位；目標水位為預測需求加安全庫存。
- **店長確認流程**：AI 產生建議 → 店長檢視/修改數量 → 確認送出補貨單。門市設定也能開啟「自動確認補貨單」，讓符合高信心度與金額上限的品項免逐筆確認。

## 5 分鐘錄音錄影腳本

1. **00:00–00:40｜情境與目標**：以資訊開發組長身分向主管說明，過去店長需要憑經驗盤點、容易缺貨或囤貨；新系統整合庫存與銷售預測，將建議交給店長確認。
2. **00:40–01:35｜首頁總覽**：展示今日待補貨品項、預計金額、低庫存警示與預測準確率；說明趨勢圖比較實際銷售與 AI 預測，庫存健康度提供管理優先順序。
3. **01:35–02:30｜模型與管理模式**：切到「預測與模型」，解釋加權移動平均與定期檢查制（R,S），帶出公式「補貨量 = max(0, 目標水位 − 現有庫存)」。
4. **02:30–03:50｜示範操作**：切到「補貨建議」，勾選商品、調整鮮乳補貨數量，搜尋商品確認明細，說明系統會同步更新品項數與預計金額。
5. **03:50–04:30｜送出與追蹤**：按「送出補貨單」，在確認視窗核對品項、金額與到貨時間，按「確認送出」，說明補貨單會交給統家物流。
6. **04:30–05:00｜自動化與效益**：切到「門市設定」，展示「自動確認補貨單」開關，說明只對高信心度且在金額上限內的建議自動送出；收尾強調降低缺貨、減少店長作業時間，並邀請主管核准試點。

> YouTube 上傳需由使用者以自己的帳號進行；錄影時可用瀏覽器全螢幕展示本頁，依腳本操作即可完成約 5 分鐘示範。
